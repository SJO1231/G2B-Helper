## 2. 판정 규칙

- **판정 값**: `충족`, `미충족`, `미검증`(사유를 함께 기록: 실행 오류·준비 실패·어댑터 불일치·대상 0건·자료 없음·증인 불성립·관측 경로 없음), `조건부(관측 기준선)`, `근거 있는 비해당`, `미확정(관측만)`.
  - `조건부(관측 기준선)`는 독립 기대 표시를 정할 수 없는 대상(F44)에서, 관측한 처음 표시를 기준으로 본 관계 판정이다.
  - 미검증·조건부·미확정은 통과 수에 넣지 않고, 해당 요구나 #13 완료의 근거로 쓰지 않는다.
- **계산 개념 구분**
  - Number 변환: 문자열을 IEEE 754 배정밀도로 바꾸는 것. 2^53(9007199254740992)을 넘으면 정수 부분도 가장 가까운 표현값으로 바뀐다.
  - 정확한 소수 계산: 10진 문자열·BigInt로 손실 없이 계산하는 것.
  - 표시 반올림: 정확한 값을 N자리로 반올림하는 것. 동률(.5) 규칙은 미확정이다.
  - 기대값은 정확한 소수 계산과 표시 반올림으로만 정하고, 동률 규칙에 따라 결과가 갈리는 사례는 쓰지 않는다. Number 경로의 결과는 어떤 사례가 Number 손실을 구별하는지 표시하는 데만 쓴다.
- **증인 전제**: 판정마다 "정상이면 반드시 관측되는 차이"가 성립하는지 먼저 확인한다(예: 검색 결과가 비어 있지 않고 필터가 실제로 행을 줄임). 증인이 성립하지 않으면 그 판정은 `미검증(증인 불성립)`이며 통과가 아니다. 실행마다 증인 성립 여부를 기록한다.
- **관측 경로**: 동작 판정은 대상별로 선언한 관측 경로(DOM 상태, 화면·모드, 다운로드 이벤트, 대상의 요청 기록)로 확인한다. 컨트롤 자체의 상태 변화(체크 표시·눌림 상태·안내 문구)는 효과로 인정하지 않는다. 관측 경로가 없는 대상은 `미검증(관측 경로 없음)`이다. 합성 시안의 관측은 실제 호스트·나라장터 실행과 구분해 `합성 관측`으로 표기한다.
- **저장소 구분**: 원천(원본 자료), 작업(편집·사용자 열), 표시(화면)를 구분한다. 어댑터는 각 판정이 어느 저장소를 읽는지 선언한다. 대상이 저장소를 분리하지 않으면 해당 판정은 `미검증(저장소 분리 불가)`로 기록한다.
- **공통 판정 함수**: 정상 fixture·결함 주입 사본·F44가 같은 판정 함수를 쓴다. 대상별로 다른 것은 요소 찾기·상태 읽기 어댑터뿐이며, 그 차이를 결과에 공개한다. 기대값과 검사 의미는 대상별로 바꾸지 않는다.
- **요소 찾기**: 가능하면 접근 가능한 이름(텍스트·aria-label)으로 찾는다. 요구된 수단이 없으면 `미충족(부재)`, 있는데 찾는 방식이 실패하면 `미검증(어댑터 실패)`로 구분한다.
- **기대값**: 사례별 고정 기대값을 이 문서에 직접 적는다. 계산은 정확한 소수 계산만 쓰고 Number를 쓰지 않는다.
- **결함 주입 결과**: §5의 결과 상태 6종을 따른다.
- **실제 결함 처리**: F44의 알려진 결함은 실패로 그대로 기록한다. 시안·제품을 고치거나 fixture·기대값을 완화하지 않는다.

### O-1 오라클 정밀도

- 기대값은 R1·P1 고정 사례표에 직접 적은 문자열이다.
- 정정: v1의 "`Number('9007199254740993.25')`가 `9007199254740992`가 됨"은 틀렸다. 실제 결과는 `9007199254740994`다. 2^53 근처의 배정밀도 표현 간격은 2라서, `…993.25`는 `…992`까지 1.25, `…994`까지 0.75 떨어져 있고 더 가까운 `…994`가 된다. 검토자 수치를 아래 임시 계산으로 독립 확인했다.
- 검산 함수(BigInt·문자열 기반)는 모든 고정 사례를 재현하는지 자체 검사한다. 검산 함수가 고정값과 다르면 검사기 결함으로 보고하며, 고정값을 고쳐 맞추지 않는다.
- **임시 계산(v2 작성 중, 검사 실행 아님)**: 저장소 스크립트·제품 코드·설치·네트워크 없이, Node v22.22.0 내장 `Number`·`toFixed`·`BigInt`와 Python 3.11.15 표준 `decimal`만 썼다. 스크립트는 작성자 임시 경로에 두었고 저장소에 넣지 않았다.

  | 원값 | 자릿수 | `String(Number)` | Number 경로 `toFixed` | 정확(올림) | 정확(짝수) | 버림 |
  |---|---|---|---|---|---|---|
  | `9007199254740993.25` | 2 | `9007199254740994` | `9007199254740994.00` | `9007199254740993.25` | 같음 | 같음 |
  | `9007199254740993.25` | 0 | `9007199254740994` | `9007199254740994` | `9007199254740993` | 같음 | 같음 |
  | `35608652.5` | 1 | `35608652.5` | `35608652.5` | `35608652.5` | 같음 | 같음 |
  | `35608652.5` | 0 | `35608652.5` | `35608653` | `35608653` | `35608652` | `35608652` |
  | `9007199254740993.75` | 0 | `9007199254740994` | `9007199254740994` | `9007199254740994` | 같음 | `9007199254740993` |
  | `0.26` | 1 | `0.26` | `0.3` | `0.3` | 같음 | `0.2` |
  | `0.123456789012345678901` | 20 | `0.12345678901234568` | `0.12345678901234567737` | `0.12345678901234567890` | 같음 | 같음 |
  | `12345678901234567890.125` | 3 | `12345678901234567000` | `12345678901234567168.000` | `12345678901234567890.125` | 같음 | 같음 |

  - 보조 확인: `BigInt(Number('9007199254740993.25'))` = `9007199254740994`, `BigInt(Number('9007199254740993'))` = `9007199254740992`, `BigInt(Number('12345678901234567890.125'))` = `12345678901234567168`.
  - Python `decimal`로 계산한 `…993.25`와 두 후보의 거리: `…992`까지 1.25, `…994`까지 0.75.
