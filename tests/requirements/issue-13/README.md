## 2. 판정 규칙

- **판정 값**: `충족`, `미충족`, `미검증`(사유를 함께 기록: 실행 오류·준비 실패·어댑터 불일치·대상 0건·자료 없음·증인 불성립·관측 경로 없음), `근거 있는 비해당`, `미확정(관측만)`. 미검증과 미확정은 통과 수에 넣지 않는다.
- **증인 전제**: 판정마다 "정상이면 반드시 관측되는 차이"가 성립하는지 먼저 확인한다(예: 검색 결과가 비어 있지 않고 필터가 실제로 행을 줄임). 증인이 성립하지 않으면 그 판정은 `미검증(증인 불성립)`이며 통과가 아니다. 실행마다 증인 성립 여부를 기록한다.
- **관측 경로**: 동작 판정은 대상별로 선언한 관측 경로(DOM 상태, 화면·모드, 다운로드 이벤트, 대상의 요청 기록)로 확인한다. 컨트롤 자체의 상태 변화(체크 표시·눌림 상태·안내 문구)는 효과로 인정하지 않는다. 관측 경로가 없는 대상은 `미검증(관측 경로 없음)`이다. 합성 시안의 관측은 실제 호스트·나라장터 실행과 구분해 `합성 관측`으로 표기한다.
- **저장소 구분**: 원천(원본 자료), 작업(편집·사용자 열), 표시(화면)를 구분한다. 어댑터는 각 판정이 어느 저장소를 읽는지 선언한다. 대상이 저장소를 분리하지 않으면 해당 판정은 `미검증(저장소 분리 불가)`로 기록한다.
- **공통 판정 함수**: 정상 fixture·결함 주입 사본·F44가 같은 판정 함수를 쓴다. 대상별로 다른 것은 요소 찾기·상태 읽기 어댑터뿐이며, 그 차이를 결과에 공개한다. 기대값과 검사 의미는 대상별로 바꾸지 않는다.
- **요소 찾기**: 가능하면 접근 가능한 이름(텍스트·aria-label)으로 찾는다. 요구된 수단이 없으면 `미충족(부재)`, 있는데 찾는 방식이 실패하면 `미검증(어댑터 실패)`로 구분한다.
- **기대값**: 사례별 고정 기대값을 이 문서에 직접 적는다. 큰 수·소수 계산은 문자열과 BigInt로만 하고 JavaScript Number를 쓰지 않는다.
- **실제 결함 처리**: F44의 알려진 결함은 실패로 그대로 기록한다. 시안·제품을 고치거나 fixture·기대값을 완화하지 않는다.
- **집계 제한**: 부분 기준의 통과로 네 시작 사례나 #13 전체 보존 검증의 완료를 선언하지 않는다.

### O-1 오라클 정밀도

- 기대값은 위 고정 사례표에 직접 적은 문자열이다.
- BigInt·문자열 기반 검산 함수는 모든 고정 사례를 재현하는지 자체 검사한다. 2^53을 넘는 사례에서는 Number 경로의 결과가 다름(예: `Number('9007199254740993.25')`가 `9007199254740992`가 됨)을 함께 기록한다.
- 검산 함수가 고정값과 다르면 검사기 결함으로 보고하며, 고정값을 고쳐 맞추지 않는다.

## 5. 정상 fixture·결함 주입 명세

- **정상 fixture**: `fixtures/`의 합성 HTML 1개로, 요구대로 동작하도록 직접 작성하며 F44 코드를 복사하지 않는다.

  - 상태 변경은 실제 DOM 이벤트로만 한다. 검사 전용 통과 도우미나 미리 고정한 통과 상태를 두지 않는다.
  - 요청 기록(합성 관측 경로)은 R4의 조회·엑셀·건수·런처 동작에만 쓴다.
  - 정상 fixture의 필수 판정이 하나라도 충족이 아니면 검사기 또는 fixture 결함으로 보고한다. 기대값이나 fixture를 고쳐 통과시키지 않고, 원인을 기록한 뒤 재검토를 받는다.
- **결함 주입 사본**: 실행할 때 정상 fixture를 OS 임시 경로에 복사하고, 위 표의 M-* 결함을 하나씩 넣는다. 사본마다 다음을 기록한다.
  - 주입 위치: fixture 안 표식 블록 ID.
  - 주입 적용 증거: 주입 전후 SHA256과 표식 블록 diff.
  - 의도 요구 ID.
  - 반드시 미충족(또는 전제 불성립)이어야 할 판정 ID.
- **검출 성공 판정**: 지정한 판정이 지정한 사유로 미충족(불성립)일 때만 성공이다. 다른 판정만 실패했거나 어댑터·파싱·준비 오류가 난 경우는 **검출 실패(생존)**이다. 다른 요구가 함께 실패하는 것은 허용한다. 생존한 주입은 통과로 세지 않는다.
- 주입 사본은 저장소에 쓰지 않는다.
