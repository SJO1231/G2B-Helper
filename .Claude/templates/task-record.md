# 과업 기록 양식

> 계획·진행·인계가 여러 세션에 걸릴 때만 기존 기록에 이 구조를 적용한다.
> 작은 작업은 대화에 남긴다. 계획·진행·최종 보고·인계를 같은 사실의 별도 사본으로 증식시키지 않는다.
> 아래의 빈 항목은 작성 양식이며 현재 작업이 완료됐다는 뜻이 아니다.

## 현재 상태

- 과업 / 사용자가 요청한 결과:
- 기록 시각 / 기준 커밋 또는 파일 상태:
- 기존 사용자 변경 / 이번 변경:
- 범위 / 비범위:
- 현재 상태: 진행 중 / 차단 / 완료 중 실제 하나를 선택
- 완료 판정에 필요한 관측:
