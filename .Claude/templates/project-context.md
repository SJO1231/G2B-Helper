# 프로젝트 사실 기록 양식

> 사용 안내: 기존 README·기여 문서·아키텍처 문서가 있으면 그곳을 갱신한다.
> 별도 기록이 필요할 때만 이 양식을 복사한다. 아래 항목은 프로젝트 사실이 아니다.
> 확인하지 않은 값은 '미확인'으로 남기고 명령·브랜치·모듈을 추측해 채우지 않는다.

- 확인일 / 확인한 기준 상태:
- 제품 목적과 대상 사용자:
- 이번 과업의 범위 / 비범위:
- 실행 환경과 버전의 정본:
- 설치·실행 명령과 확인 근거:
- 변경 종류별 검증 명령 / 실행 조건 / 미검증 자원:
- 핵심 모듈과 의존 방향:
- 공유 API·의미 판정·데이터의 소유자:
- 제품·아키텍처·검증·사용법의 기존 정본 경로:
- 사용자 데이터·비밀값·원본 보호 경계:
- Git·PR·배포의 프로젝트 절차와 현재 승인 범위:
- 중요한 기존 결정·실패 기록의 위치:
- 해결해야 할 질문:

필요하지 않은 항목은 근거를 적고 생략한다. 이 양식을 완성하는 일을 모든 작업의 선행조건으로 만들지 않는다.
