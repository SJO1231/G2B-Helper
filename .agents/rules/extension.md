# 확장 구현 규칙
- 요구 기준은 docs/EXTENSION_REQUIREMENTS.md, 원천 키/공개 용어는 docs/GLOSSARY.md.
- 메인은 위젯/팝업 조립과 명령 전달만 담당. 기능은 소유 플러그인과 공개 Gateway 명령으로 분리.
- 사용자 데이터는 SQLite. chrome.storage.session은 실행 중 알람/원천 탭 문맥에만 사용. IndexedDB fallback 금지.
- 추출은 읽기만. 등록/저장 버튼 이전에는 표·규칙·raw 이벤트 쓰기 금지.
- 수집 URL/화면 조건은 같은 frame에서 평가. 수동1회/자동/추출의 의미를 바꾸지 않음.
- 원천 탭을 모든 popup/스크립트/폴더 문맥에서 유지. 현재 활성 창을 원천으로 다시 추측하지 않음.
- 충돌/실패 시 편집 유지, 원자적 저장, 숫자코드/decimal/0/false 보존.
- UI 인수검사는 위젯 크기·접기/이동·배경 페이지 사용·독립 창·저장 재열기까지 확인. 브라우저 모의 API와 실제 설치를 별도 표시.

- 화면 기준은 v4.1의 단순한 리모컨·근처 기능창·큰 그리드다. v3/v4 피드백과 최신 정정을 대조하고 그대로 복제했다고 요구 충족으로 간주하지 않는다.
- 일반 기능창은 페이지 내부 iframe이며 Chrome 새 창을 만들지 않는다. 미저장 닫기는 pce:close-check로 기능 소유자가 차단한다. 스티커만 크기 조절을 제공한다.
