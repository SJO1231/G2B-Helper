## 운영·유지보수
- AGENTS.md, .agents/rules/extension.md, .agents/skills/pce-extension/SKILL.md에 최신 경계를 기록했다.
- .agents/hooks/README.md는 실제 npm 검사를 설명한다. Codex/Windows 전역 이벤트 hook 설치를 뜻하지 않는다.
- 업무 제어·Native·UI 호환을 파일 소유권으로 나누어 병렬 구현하고, 모의 API UI와 실제 확장 경로를 구분해 검수했다.
- 추가 업무 스키마를 JSON에서 임의 추론해 생성하지 않는다. 추출 화면에서 사용자가 표·규칙 등록을 명시하면 해당 논리 표를 생성한다.
- 이번 실행은 TypeScript 175개/16파일·경계 17소스/확장 68입력·타입/빌드, Native 45개, UI harness 29개, 실제 격리 확장 16개 통과다. 실행 시점과 경로는 TEST_REPORT.md에 기록한다. 이전 UI 20개·Workspace 36개·패키지 기록을 변경 후 새 검증으로 합산하지 않는다. 실행 안내: EXTENSION_INSTALL.md.
- 최종 스티커 배경·상태문구 수정 뒤 타입/빌드와 실제 runtime 16개를 재확인했다. UI harness 29개는 같은 DB 기능 버전의 수정 전 실행이며 검사 경로를 구분한다. 배포 ZIP은 `dist/PCE-extension-0.3.0.zip`, 패키지 기록의 75개 파일 검증 통과다. 실제 사용자 Chrome 운영 등록은 수행하지 않았다.

## 이번 변경과 남은 요구

v4.1 전체 복제가 아닌 형태·단순함을 기준으로 화면을 재구성했다. v3/v4 피드백의 본문 우선 메모·작은 도구, 그리드 중심 표 관리, 클릭 선택 후 타이핑을 반영하고 SQL·CAS·원본 보존·백업 경로는 유지했다. v5 이벤트/직링크 전체, 런처 정렬/설명/화면 규칙 저장, 반복·알림·칸반·다중 드래그, 메모 색상·상단 고정 지속 설정은 계속 미완료 요구다. 실제 나라장터 및 한글 인쇄 배치 검증도 별도다.
