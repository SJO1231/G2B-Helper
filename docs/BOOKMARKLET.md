# PCE 올인원 북마크릿 사용

## 설치

1. `dist/bookmarklet/install.html`을 Edge/Chrome에서 연다.
2. **PCE 올인원** 링크를 북마크 막대로 드래그한다. 기존 북마크를 교체해도 사이트 IndexedDB는 삭제되지 않는다.
3. 설치 전에는 같은 폴더의 `demo.html`에서 **PCE 올인원 열기**를 누른다. 연습용 합성 자료이며 실제 나라장터 검증이 아니다.
4. 자료가 있는 사이트에서 북마크를 실행한다. 같은 사이트의 보관함이 열린다.

하나의 번들에 React·Tabulator·SheetJS·HWPX ZIP 처리를 포함하며 실행 중 CDN을 읽지 않는다. 북마크 URL이 크므로 실제 북마크 막대와 사이트 CSP 동작은 별도 확인 항목이다. 연습 화면의 javascript 링크는 Edge headless에서 검증했다.

## 업무 자료를 DB에서 편집

- **업무**에서 1회 수집/자동 수집은 지정 화면만 보관한다. 임시 추출은 수집 대상 설정과 별개다.
- 한글 사전의 표만 보기가 기본이다. 결과가 없으면 **모든 표** 보기나 키 사전을 확인한다.
- 직접 추출한 `pointInfo/tables` JSON은 **원본 추출 파일**로 열 수 있다. 아직 수집 이벤트를 쓰지 않는 임시 보기다.
- **표를 DB 자료집으로**에서 표 이름을 선택한다. **DB**에서 그 자료집을 열고 클릭 편집 후 **표 저장**으로 확정한다.
- Import의 추가 열/행도 저장 전 버퍼에 들어간다. 실패하면 편집 내용이 남는다. 화면에 숨긴 빈 행을 자동 삭제하지 않는다.

북마크릿 DB는 이 사이트의 IndexedDB다. SQLite의 조달 정규화 비교·반영은 전달 JSON을 기존 데스크탑에서 검토하는 별도 경로다.

## 텍스트·HWPX 템플릿

1. DB에서 사용할 레코드를 클릭한다. 다른 탭에서도 같은 선택을 사용한다.
2. **텍스트 템플릿**의 열 버튼 또는 `{{열 이름}}`·`{{JSON열.경로}}`로 연결한다.
3. **조건에 따른 출력**에서 AND/OR 조건과 충족/불충족 문구를 작성하고 **본문에 삽입**한다. 적용 미리보기 후 MD를 다운로드한다.
4. **HWPX 문서**에서 원본 파일을 연다. 문단, 텍스트 구간 또는 **셀 선택**을 클릭한다.
5. 앵커 이름을 정하고 DB 열을 선택하거나 치환식을 작성한다. **앵커 추가/연결 수정**, **HWPX 템플릿 저장**을 차례로 누른다.
6. **HWPX 적용 미리보기**를 확인하고 **생성 HWPX 다운로드**로 새 파일을 받는다.
7. 저장한 템플릿에서 **파생 템플릿 만들기**를 누르면 원본 ZIP을 참조하는 별도 양식이 된다. 파생이 참조 중인 마스터 삭제는 차단한다.

**새 문단·표 추가:** 원본 구조에서 본문 문단을 선택하고 **앵커 동작**을 바꾼다.

- **새 문단 추가**: 출력식의 줄바꿈마다 문단을 추가한다. 조건 결과가 빈 문자열이면 추가하지 않는다.
- **배열 표 추가**: 선택한 DB 레코드의 JSON 배열을 고르고, 열 제목·출력식·표 너비·행 높이·원본 테두리를 지정한다. 열은 배열 첫 행을 기준으로 제안하며 추가·삭제·수정할 수 있다. 빈 배열은 표를 추가하지 않는다.
- 각 배열 행은 `{{row.코드}}`, 현재 DB 레코드는 `{{기관명}}`, 계산은 `{=[row.단가]*[row.수량]}`처럼 연결한다. 점·기호가 들어간 실제 열 이름은 자동 생성된 `path:` 토큰을 사용해 중첩 경로와 구분한다.
- 같은 문단에 문단과 표를 함께 넣으려면 **같은 위치에 별도 앵커 만들기**를 누른다. 앵커 목록 순서대로 추가한다.
- 새 문단과 셀에는 선택 문단의 문단·스타일 및 첫 글자 서식을 적용한다. 새 객체 ID만 발급하고 원본 서식 자원은 바꾸지 않는다. 표 안에 표를 추가하거나 병합 셀을 만드는 기능은 아직 없다.
- 생성 미리보기에서 앵커를 새로 지정하지 않는다. **원본 구조**로 돌아가 지정한다. 매번 불변 원본에서 생성하므로 다시 생성해도 문단·표가 누적되지 않는다.

한 표는 데이터 1,000행·30열, 셀/문단 각각 10,000개까지다. 새 출력 전체는 8MB 이하로 제한한다. 마스터 변경으로 파생·하위 파생의 앵커가 깨지면 전체 저장을 중단하며 편집 내용은 유지한다.

치환 예: `{오늘+2}`, `{품명:대체:기존:변경}`, `{품명:1:3}`, `{=단가*수량}`. 기존 `[같음:종류:물품]…[/같음]`·`[다름:상태:취소]…[/다름]`도 지원한다. 기존 기안 프로그램과 완전 호환을 주장하지 않는다.

HWPX 뷰는 구조 확인용이다. 한글의 페이지 배치·모든 객체 렌더링·교차 문서 서식 병합은 미완료다. 컨트롤이 있는 문단 전체는 치환하지 않고 텍스트 구간을 선택할 수 있다. 수정 대상 밖의 ZIP 항목은 내용 바이트를 보존하지만 압축 바이트·ZIP 시간 등은 동일하지 않을 수 있다. 기존 Preview 이미지는 원본이므로 한글에서 다시 저장하여 갱신해야 한다. 생성 문서의 실제 한글 열기·인쇄는 별도 검증이 필요하다.

## 보관과 검증 상태

**설정·백업**의 전체 백업은 수집 원본, DB 자료집, 메모·일정, 런처, 관계, 텍스트/HWPX 템플릿을 담는다. 복원은 미리보기를 읽은 뒤 명시적으로 전체 교체한다. 자동 수집을 정지하고, 미리보기 이후 자료가 바뀌었으면 교체를 중단한다. 기존 사이트 보관함을 자동 삭제하지 않는다.

설치 묶음에서는 [기능 충족 현황](REQUIREMENTS_STATUS.md)과 [검증 보고서](TEST_REPORT.md)를 읽는다. 저장소의 원본 대장은 `docs/BOOKMARKLET_REQUIREMENTS_MATRIX.md`다. 현재 모든 요구가 완성된 버전은 아니다. PC 파일 실행·전역 단축키 등은 연결 방식의 사용자 답변이 필요하다.
