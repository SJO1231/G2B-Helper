## 검증 위치

최종 실행 수와 한계는 `TEST_REPORT.md`, 기능별 실행 자료는 `dist/evidence/extension` 및 `dist/evidence/database`에 기록한다. 샘플·합성 화면·실제 MV3 통신과 실제 나라장터 운영 검증을 구분한다. 기능 설명을 줄였다는 이유로 미구현 요구를 삭제하지 않는다.
