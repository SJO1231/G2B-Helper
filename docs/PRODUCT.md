# PCE 요구사항 기준서

현재 실행 환경·저장·UI 기준은 2026-09-28 사용자 정정을 보존한 [EXTENSION_REQUIREMENTS.md](EXTENSION_REQUIREMENTS.md)다. 앞선 「PCE 요구사항 기준서 및 1·2·3차 구현 계획」에서 충돌하지 않는 기능은 계속 유지한다. **1차는 기준점이며 전체 완료가 아니다.** 요구사항은 코드 존재나 시험 통과와 구분한다.

## 출처
- S01 사용자 프로그램 개요: 범용 Excel-like DB, 나라장터, 브라우저·데스크탑, 문서·일정·도구.
- S02 메모·일정 답변: 달력·아이젠하워·칸반, 반복, 다중 선택·드래그.
- S03 추출·관계 정정: 빈칸 제외, 업무키 별도 설정, 추가 업무 스키마는 사용자 허가.
- S04 관계·필터 정정: 중앙 관계 표/테이블 설정, 중복 정책, 브라우저 간단/데스크탑 상세.
- S05 이전 정정: 북마크릿 IndexedDB→JSON, 2·3차 배치, JSON 출력, 복수 텍스트 AND/OR. 북마크릿 실행·IndexedDB 저장 선택은 S13으로 대체되었으며 나머지 기능 요구는 유지한다.
- S06 질문 답변: 빈 표·행·열 기본 숨김+옵션(표시만), 저장/관계 중복 독립, 계획 범위/날짜 분리, 하나의 기간 일정.
- S07 최종 구현 요청: 앞선 계획 전체 구현 승인. 설계 제안의 출처는 사용자 원문으로 바꾸지 않는다.
- S08 제공 자료 출처 답변: 사용자가 실제 화면에서 직접 추출했으며 같은 조건에서는 내용·구조가 같다고 확인. 해당 자료를 구조 기준으로 삼고, 브라우저 권한·frame 실행 검증과 구분한다.
- S09 수집·실행 정정: 지정한 화면에서만 수집하고 북마크릿에도 동일한 제한을 적용. 데스크탑 WebView2 오류는 원인을 확인한 뒤 조치.
- S10 이전 북마크릿 요청: 업무·DB·메모/일정·런처·수집·추출·Import/Export·텍스트/HWPX 템플릿과 조건 치환을 올인원 북마크릿으로 제작. 배포 방식은 S13으로 대체되었으며 기존 기능 요구는 유지한다.
- S11 참고 도구 정정: hwpx-filler 외의 Python HWPX 도구도 찾아 참고하고, 뷰어에서 위치를 선택하여 DB 열과 앵커·템플릿을 연결한다. 참고 코드의 설명·설계는 사용자 요구와 별개다.
- S12 작업 진행 조건: 계속 수행하되 아스트라가 필요한 상황이라고 판단하면 정지하고 사용자에게 알린다.
- S13 최신 확장·SQL 정정: 확장은 페이지 전체를 덮지 않는 업무 리모컨과 기능별 독립 팝업. 업무·수집/추출·메모/일정·런처·DB·사전·문서·탐색기·데스크탑 문맥을 유지하고, IndexedDB 없이 확장과 데스크탑이 같은 SQL DB를 사용한다. 상세 1~14항은 EXTENSION_REQUIREMENTS.md의 E01~E14다.
- S14 위젯·자동 수집 답변: 페이지 위의 작은 이동형·접기 위젯을 선택. 자동 수집은 시작한 탭별로 시작/정지하며 패널 닫기와 구분한다.

## 공통 동작
- 추출은 한글 매핑 표만(기본)/한글 매핑 전체/모든 표/모든 자료. 숨김은 표시만. 0/false 유효.
- 현재 로딩 자료만 수집. 누락·빈 배열은 삭제 아님. 신규/보완/충돌 분리, 필드별 승인·버전 검사.
- 확장 수집은 같은 frame의 URL과 화면 조건을 원본 저장 전에 검사한다. 임시 추출은 조건과 무관하게 현재 자료를 읽으며 추출만으로 DB에 쓰지 않는다. 명시적 보관/규칙 등록과 수집을 구분한다.
- 자동 수집은 시작한 탭에만 적용한다. 위젯/팝업 닫기는 자동 정지가 아니다. DB 연결 실패는 실패로 알리며 별도 브라우저 DB에 저장하지 않는다.
- 관계 사용자 설정 우선. 접수/공고/계약 번호+차수 보조 매칭. 부모 조건과 물품 식별 분리. 별도 요청번호를 접수로 바꾸지 않음.
- 선행 0·정확한 decimal·frame 출처 유지. Grid 변경 묶음 명시적 저장, 실패 시 버퍼 유지.
- 포함/일치는 하나 이상, 제외는 모두 불일치. 중첩 AND/OR·빈값·원값/표시값 설정.
- JSON 원문/계층/요약/경로 열/배열 표. 물리 테이블 자동 생성 금지.
- Import 표 영역·헤더·추가 열·중복 미리보기. 일반 자료 중복 허용, 제거는 승인 후.
- 이전 북마크릿 원본·검증 자료는 보관한다. 당시 내보내기는 자료 삭제나 데스크탑 반영 완료를 뜻하지 않았으며 현재 활성 배포 기능으로 표시하지 않는다.
- 백업은 DB 외 설정·규칙·사전·템플릿 포함. 외부 파일 참조와 실제 파일 포함 구분.

## 문서 책임
현재 확장 정정은 EXTENSION_REQUIREMENTS.md, 누적 요구사항은 이 파일, 설계·대체 이력은 DECISIONS.md, 명칭은 GLOSSARY.md, 구현과 실제 검증 상태는 STATUS.md를 따른다. 후속 기능은 삭제하지 않는다. 이전 북마크릿 충족 대장은 당시 산출물의 이력이며 현재 확장 요구 충족 증거와 구분한다.
