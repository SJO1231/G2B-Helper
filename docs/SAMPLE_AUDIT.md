출처 근거: 사용자는 제공 파일을 실제 화면에서 직접 추출했으며, 동일 조건에서는 화면의 내용/구조가 제공 자료와 같다고 확인했다. 이는 샘플 출처에 대한 사용자 확인이다. 이 확인은 현재 실행 중인 G2B 연결, 브라우저 권한, frame 접근, 전체 화면 커버리지 또는 수집 결과 재현을 뜻하지 않는다.
