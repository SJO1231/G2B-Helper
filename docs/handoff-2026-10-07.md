## ④ 로컬에서만 확인할 수 있어 못 한 것

이 세션은 리눅스 클라우드 컨테이너에서 돌았다. 검사는 GitHub Actions CI(Ubuntu, Playwright Chromium headless)로만 했다. 아래 항목은 하나도 확인하지 않았다.

- **설치된 확장:** 실제 Chrome/Edge에 로드한 확장의 동작과 버전. CI 로그의 확장 빌드 성공은 설치·로드 확인이 아니다.
- **Native Host:** 호스트 등록, 실행, 메시지 프레이밍의 실제 왕복.
- **Studio 서버:** HWPX Studio 쪽 서버 실행과 연동.
- **SQLite:** 실제 SQLite 파일 읽기·쓰기와 기존 사용자 DB 보존.
- **한글:** 로컬 한글 환경(입력기, 글꼴, 한글 프로그램에서 문서 열기)에서의 입력과 표시. CI 로그의 한글 메시지 출력은 이 확인이 아니다.
- **그 밖:**
  - 하네스 wrapper(`node scripts/harness/cli.mjs doctor/start/guard/run/verify`)는 이 세션에서 실행하지 않았다. 따라서 hooks의 실제 로딩·차단은 미검증이다.
  - 실제 나라장터 화면과 사용자 프로필도 확인하지 않았다.
