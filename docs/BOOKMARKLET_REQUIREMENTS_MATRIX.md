## 구현을 위해 추가한 선택 — 사용자 원문과 구분

- 기존 origin-local 저장소 version 1을 유지하며 플러그인 문서를 namespaced 설정에 보관: D15.
- 앵커는 외부 정의로 보관하고 원본 XML에 새 임의 속성을 삽입하지 않음. 위치·원문 검사와 겹침 차단: D16.
- 템플릿은 코드 실행 없이 제한된 문법으로 치환, 크기 4MB·참조 깊이 12·치환 횟수 제한: D17.
- ZIP 라이브러리와 빌드/테스트 도구 수정 버전 고정: D18.
- 원본에 대한 선언적 삽입과 같은 문서 서식 참조, 경로 지문·하위 파생 검증, 특수문자 키의 명시적 경로 토큰: D19.

실행 증거는 `artifacts/bookmarklet-prototype-verification.json`, `artifacts/bookmarklet-hwpx-verification.json`, `artifacts/bookmarklet-hwpx-insertion-verification.json`, `artifacts/ui-verification.json` 및 TEST_REPORT.md를 따른다. 실제 G2B와 한글 페이지 검증은 OPEN이다.
