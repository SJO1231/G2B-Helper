# 기능별 합격 기준

요구 출처는 PRODUCT.md, 실행 결과는 STATUS.md 참조.

## 1차
- U04: 확장/북마크릿 저장→재열기→반영, export 후 보관, 동일 이벤트 중복 없음·내용 변경 재비교. 손상 파일 부분 반영 없음.
- U05/U06: 기간·조회·건수·Excel 실제 화면 검증. 규칙 없는 화면 추정 클릭 금지. 자동 기본 꺼짐, 오류에도 정지·감시 해제.
- U04/U06: 확장·북마크릿 저장 전 지정 화면 검사. 미지정·혼합 업무 차단, 관계없는 frame의 자료 제외, 정책 로딩 실패 시 차단, 시작 도중 정지해도 다시 활성화되지 않음. 실제 사이트 권한 검증과 별도 기록.
- U07/C01: 네 추출 모드, 빈 표/행/열 옵션, 0/false 유지, 원본 불변. 임시 표·규칙화·XLSX/CSV.
- U08/U09: 번호+차수 보조, 부모/물품 식별 구분, 차수 누락 미연결, 승인 없는 추가 업무 표 없음. 별도 요청번호 접수 변환 금지.
- U10/C02: 두 화면의 동일 관계 수정, 저장 중복/다중 매칭 독립, 영향 미리보기·동시 변경 재검사, 원본 병합/삭제 없음.
- U11/U12: 표/열 생성, 선택·입력/F2·더블클릭·Enter/Tab/Esc·사각 범위·붙여넣기·삭제·채우기. 숨긴 행 보존, 실패 시 롤백·버퍼 유지, SQL 읽기 전용.
- U12/U13: 사칙·날짜·합계/평균, 수식 세션만·적용값 저장. 복수 값/동일 열/다중 열/중첩 AND/OR·빈값·사전값, 환경별 의미 동일.
- U14: JSON 요약·계층·원문·가상 경로 열·배열 표·출력. 누락/null/빈문자 구분. 표시로 영구 스키마 생성 금지.
- U15/U16: 키/코드 사전·헤더·화면 고정, 숨김/제외 분리. 원본·frame·시각·실패·부분 상태, 필드별 충돌 승인과 버전 검사.
- U11 입출력: 첫 시트·앞부분 공백·영역/헤더 조정·추가 열 미리보기·미매핑 유지·중복 미리보기. 연락처 중복 허용.
- U17/U19/U20: 일반/화면/레코드 메모·기본 일정, 텍스트 마스터/파생·DB 필드·생성·브라우저 선택·뷰어.
- U21/U22: 파일/폴더 연결·생성 규칙, 런처 파일/URL/직링크/수동 스크립트. 기본 위치/생성 위치/1~3열/드래그 배치 요구 유지.
- U23: 전체/종류별 복원, 설정/관계/템플릿 포함. 외부 파일 참조/실물 구분, 의존 관계·충돌 미리보기.
