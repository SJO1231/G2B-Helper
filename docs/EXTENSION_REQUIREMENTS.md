## 설계 선택 — 사용자 원문과 구분
- MV3 isolated-world 위젯 + MAIN-world WebSquare 읽기/업무 조작, 확장의 feature.html을 담은 페이지 내부 iframe 패널. 원천 탭 ID를 모든 기능 패널에 전달하여 활성 창 혼동을 막는다. 별도 브라우저 windows popup은 현재 표시 방식이 아니다.
- Native Messaging와 기존 Python SQLite Gateway 재사용. 원본 참고 자료와 이전 북마크릿 파일은 삭제하지 않되 활성 빌드에서 제외한다.
- 자동 수집은 현재 MV3 알람의 30초 주기로 시작. 주기·이벤트 보조 감지는 설계 선택이며 실사이트 테스트를 요구 충족으로 대체하지 않는다.
- UI 방향은 v4.1 업무 리모컨의 간결한 형태를 참고하여 340px 위젯과 목적별 페이지 내부 패널로 조립한다. 기존 밝은 녹색 화면 계승은 이전 설계 선택이며 최신 패널 정정의 고정 조건이 아니다. 글자/배경 대비와 기능 접근을 보존하고 새 브랜딩·전체화면 모달을 기본 화면으로 만들지 않는다.

## 변경·시험 기록
원본 코드의 존재, 자동 시험, 실제 확장 설치/Native 연결, 실제 나라장터 검증은 별개다. 화면 제어에 접근할 수 없는 경우 추정 성공을 표시하지 않는다. 추가 업무 스키마는 명시적인 사용자 등록 동작 외에 생성하지 않는다.

화면 메모는 생성 당시 안정적인 화면 조건에 연결한다. WebSquare의 임의 생성 ID만으로 화면을 식별하지 않는다. URL+areaCd+depth1+depth2로 식별하며, 조건 편집과 실제 사이트 감지는 별도 검수한다.

v4.1의 업무 조작·설명·런처별 설정·화면 조건 기전은 원본과 대조하며 임의 삭제하지 않는다. 원본의 IndexedDB/eval 방식을 재도입한다는 뜻은 아니다. SQL 공유·Gateway·원본 보존·CAS·백업 계약은 유지한다.

v5 이벤트/직링크 전체, 런처 정렬·설명·화면 규칙 저장, 반복·알림·칸반·다중 드래그, 메모 색상·상단 고정의 지속 설정 등은 요구 범위에 계속 포함된다. 최신 상세 정정과 휴지통 보관·복원 선택 확정은 `UI_REVISION_20260929.md`가 기준이다. 화면 단순화나 기본 스티커 인스턴스가 이 기능들의 완료를 뜻하지 않는다. 구현·검증 여부는 STATUS.md 및 TEST_REPORT.md에서 구분한다.
