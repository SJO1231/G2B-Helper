# PCE 확장 실행 안내

현재 배포물은 **페이지 위젯 + 페이지 내부 기능창 + SQLite Native Host**입니다. 북마크릿과 IndexedDB는 사용하지 않습니다. 요구사항 전체 완료판은 아니며 남은 범위는 `STATUS.md`에 기록합니다.

## 설치
1. `dist/PCE-extension-0.4.0.zip`을 이동하지 않을 폴더에 압축 해제합니다. 저장소에서 바로 사용할 때는 `dist/extension`을 사용합니다.
2. Chrome 138 이상에서 `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램을 로드합니다** → 패키지의 `extension` 폴더를 선택합니다.
3. PCE 카드에 표시된 확장 ID를 복사합니다.
4. 패키지 폴더에서 PowerShell을 열어 다음을 실행합니다. `복사한확장ID`만 바꿉니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -ExtensionId 복사한확장ID -Browser Chrome
```

이 명령은 현재 사용자 HKCU의 PCE Native Messaging 등록을 만들고, 확장 ID 하나를 허용합니다. 관리자 권한은 필요하지 않습니다. 패키지 폴더를 옮기면 다시 등록하세요. 이미 다른 PCE 확장 ID를 등록했다면 이 등록으로 교체됩니다.

저장소에서 직접 등록하려면 다음을 사용합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File E:\PROGRAM\PCE\native\install_host.ps1 -ExtensionId 복사한확장ID -HostExe E:\PROGRAM\PCE\dist\desktop-v4\PCE.NativeHost\PCE.NativeHost.exe -Browser Chrome
```

## 사용
- 자료가 있는 웹 페이지에서 확장 아이콘을 누르면 작은 위젯이 열립니다. 제목 부분으로 이동하고 `−`로 접습니다. 다시 아이콘을 누르면 숨김/표시됩니다.
- **업무:** −1년·+1년·조회·엑셀 순서입니다. 건수는 목록 또는 직접 숫자로 입력합니다. 연도 이동 후 조회는 체크박스로 선택합니다. 요소가 여러 개일 때만 선택 창이 열립니다. 변경한 건수를 서버가 실제 허용하는지는 사이트 동작을 확인해야 합니다.
- **자동:** 이 탭만 30초마다 조건에 맞는 로딩 자료를 수집합니다. 창을 닫아도 계속되며 탭별 정지 버튼으로 멈춥니다. 이미 Native에 보낸 저장은 완료될 수 있습니다. 충돌은 수집 관리에서 검토합니다.
- **수집:** 등록 조건이 일치하는 원본을 한 번 보관하고, 수집 관리에서 비교·반영합니다.
- **추출:** 조건과 관계없이 현재 페이지를 읽고 위젯 근처 기능창에서 frame·표를 고릅니다. 보기의 기본값은 한글 매핑 표이며, 빈칸 숨김은 원본에 영향을 주지 않습니다. 내 자료 복사 또는 표·규칙 등록을 명시적으로 눌러야 DB가 변경됩니다.
- **메모/일정:** 공통 또는 현재 화면 고정. 여러 WebSquare 화면이 감지되면 상세창 상단에서 연결 화면을 고릅니다. 일간·주간·월간·아이젠하워는 상세 창에서 봅니다.
- **런처:** `+`에서 URL·스크립트·파일·프로그램·폴더 버튼을 추가합니다. 사용자 스크립트는 Chrome 확장 세부정보의 사용자 스크립트 허용을 켜야 합니다.
- **문서:** 저장한 기안문·HWPX 템플릿 버튼을 누르면 바로 생성합니다. 화면의 전체 업무키와 일치하는 레코드 하나가 있으면 연결하고, 필요한 경우 DB 버튼에서 그리드로 선택합니다. 상세에서 템플릿을 편집합니다. HWPX는 구조 뷰어에서 문단/셀을 선택하여 앵커를 만듭니다. 원본은 보존하며 생성 파일만 다운로드합니다.
- **DB:** 표 편집은 저장 버튼에서 반영됩니다. 선택 레코드의 문서 생성·업무 폴더 버튼은 같은 레코드 ID를 전달합니다.
- **업무 폴더:** 기본 다운로드 폴더 또는 연결한 레코드의 업무 폴더를 보여줍니다. 설정에서만 기준 경로를 바꾸고, 폴더·파일은 더블클릭으로 엽니다.

## 저장과 점검
SQLite 기본 위치는 `%LOCALAPPDATA%\PCE\pce.sqlite3`입니다. 데스크탑 기본 실행도 같은 위치를 사용합니다. 별도 `--database`로 실행한 데스크탑 DB는 자동으로 연결하지 않습니다. Native Host는 필요할 때 확장이 실행하며 localhost 서버를 사용하지 않습니다.

연결 오류가 나면 확장 ID, Native EXE 경로, 설치 등록을 확인합니다. 실패를 브라우저 별도 DB로 우회하지 않습니다. Native 요청은 UTF-8 60MiB, 응답은 총 100MiB로 제한하며 큰 문서 묶음은 오류를 표시합니다. HWPX 구조 보기는 한글 프로그램의 페이지 배치와 동일한 렌더링이 아닙니다.

현재 사용자의 실제 Chrome 프로필에는 자동 설치하지 않았습니다. 분리된 Edge 프로필·임시 SQL DB의 실제 Native 연결 검증과 실제 나라장터 운영 검증은 별개입니다.

## 0.4 업데이트
기존 설치가 `dist/extension`을 사용하면 Chrome 확장 관리에서 새로고침하고 업무 페이지도 새로고침하세요. 패키지를 별도 폴더에 풀었다면 새 `extension` 폴더를 로드하고 해당 확장 ID로 `install.ps1`을 실행합니다. 새 Native Host를 사용하도록 브라우저의 기존 PCE 연결도 종료 후 다시 여세요. DB 파일은 기존 위치를 유지합니다.

화이트/블랙은 위젯 상단 설정에서 변경합니다. DB는 업무·공통·시스템별 표와 통합 뷰를 제공합니다. 빈 행에 입력하고 표 끝 +로 열을 추가한 뒤 저장합니다. 메모 +는 빈 스티커를 즉시 열며 본문은 자동 저장됩니다. 휴지통은 보관·복원이 가능하고 창의 ×는 닫기입니다. Excel 취합은 각 파일의 첫 시트 헤더를 확인하고 같은 헤더에 해당하는 열만 이어 붙입니다.
